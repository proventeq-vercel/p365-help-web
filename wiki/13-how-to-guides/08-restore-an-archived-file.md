# How to Restore an Archived File

When Proventeq365 archives a file, it can leave a **stub link** in the file's original SharePoint location. Opening the stub link takes you to the archived file's page, where you can **download** a copy (the file stays archived) or **restore** it to its original location (the file is removed from the archive and becomes active again).

## Before you begin

- The file must have been archived with **Replace with Stub** enabled. See [How to Archive Obsolete Content](./07-archive-obsolete-content.md).
- You need access to the original file location. The stub link is available to every user who could access the original file.

## Steps

1. In SharePoint, open the library and folder where the file was originally stored.
2. Open the **stub link** that replaced the file. You are redirected to the archived file's page, which shows the **file name** and its **archive status**.
3. Choose what to do with the file:
   - Select **Download** to save a copy to your computer. The file **remains archived** and is **not** restored to SharePoint.
   - Select **Restore** to return the file to its original location. The file is **removed from the archive** and becomes **active** again.

## Result

- After **Download**, you have a local copy and the archive is unchanged — use this when you need the file temporarily.
- After **Restore**, the file is back in its original SharePoint location and is no longer in the archive — use this when the file is needed for ongoing work.
